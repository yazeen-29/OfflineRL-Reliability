# P1 Protocol Amendment 002

Date:
2026-08-28

Status:
Approved before publication-scale P1 data collection.

Change:
The diagnostic 100-state pilot now samples five decision states from
each of twenty clean evaluation episodes.

Rationale:
The prior 20-state implementation audit demonstrated valid support
distances but used sequential states from a single episode. Such states
are temporally correlated. Episode-balanced pilot sampling provides a
more informative diagnostic of the predictor/outcome pipeline before
full multi-seed collection.

No primary outcome, primary horizon, or scientific hypothesis was
changed.

This amendment applies to the diagnostic pilot sampling rule only.
