# P10 Standalone OOD Detection Protocol

## Objective

Evaluate whether the frozen diagnostic signals can independently
distinguish in-distribution observations from controlled observation
shifts, without using downstream consequence C10 as the outcome.

## Primary OOD definition

For the frozen consequence datasets:

- ID: sigma = 0
- OOD: sigma > 0

The controlled sigma value is the ground-truth shift label for this
evaluation.

## Frozen cells

1. IQL Hopper
2. IQL HalfCheetah
3. IQL Walker2d
4. CQL Hopper
5. CQL HalfCheetah
6. CQL Walker2d

## Independent unit

Policy seed within each cell.

Five policy seeds are evaluated independently.

## Frozen population

Use the existing frozen H=10 records only.

No dataset regeneration, resampling, RL training, checkpoint
modification, or consequence recomputation is permitted.

## OOD scores

Evaluate the following raw diagnostic signals as OOD scores:

### O1: Action disagreement

Higher action disagreement = higher OOD score.

### O2: Support distance

Higher support distance = higher OOD score.

### O3: Twin-critic disagreement

Higher twin-critic disagreement = higher OOD score.

No C10 or downstream consequence is used to construct these scores.

## Primary evaluation

For every cell, diagnostic score, and held-out policy seed:

1. retain H=10 observations;
2. label sigma=0 as ID;
3. label sigma>0 as OOD;
4. calculate AUROC;
5. calculate Average Precision;
6. report prevalence.

No fitted parameters are required for the primary raw-score
evaluation.

## Shift-severity sensitivity

For each nonzero sigma separately:

- compare that sigma level against sigma=0;
- calculate AUROC;
- calculate Average Precision.

Each sigma-specific comparison has equal numbers of ID and shifted
observations within each policy seed.

## Directionality audit

Verify that each score is oriented so that higher values imply greater
OOD status.

If a score has no rank variation, report AUROC/AP as undefined rather
than modifying the score.

## Seed-level summaries

For each cell and score report:

- mean AUROC
- SD AUROC
- mean Average Precision
- SD Average Precision
- five individual seed values

Seed summaries are descriptive.

The five policy seeds remain the independent replication units.

## Interpretation boundary

P10 evaluates detection of the controlled synthetic observation
shift represented by sigma.

It does not establish detection of arbitrary real-world OOD states,
distributional changes outside the frozen shift family, causal
faithfulness, or universal OOD detection capability.

The OOD label is generated by the experimental shift parameter and is
not an independently annotated deployment dataset.

## Reproducibility

Record:

- repository commit
- source-data hashes
- protocol hash
- cell
- policy seed
- sigma levels
- score definitions
- software versions
