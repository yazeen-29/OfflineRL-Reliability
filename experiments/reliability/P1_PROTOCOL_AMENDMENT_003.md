# P1 Protocol Amendment 003

Date:
2026-08-28

Status:
Approved before publication-scale P1 data collection.

Purpose:
Define an expanded diagnostic dose-response pilot before
multi-seed P1 collection.

Diagnostic extension:

The 100-state predictor-completeness diagnostic will be extended
across the seven predefined Gaussian observation-shift levels:

    0.00
    0.01
    0.025
    0.05
    0.10
    0.20
    0.30

The same episode-balanced decision-state set is reused across
shift levels.

Purpose:

1. Determine whether action instability changes coherently with
   perturbation magnitude.

2. Determine whether counterfactual consequence magnitude changes
   coherently with perturbation magnitude.

3. Determine whether support distance contributes predictive information
   beyond local action instability.

4. Detect any obvious threshold, saturation, or non-monotonic behavior
   before publication-scale multi-seed collection.

This is diagnostic only and cannot be promoted directly into final
paper evidence.

No primary P1 hypothesis, primary horizon, or primary outcome is changed.
