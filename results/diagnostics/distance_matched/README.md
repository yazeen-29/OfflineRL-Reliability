# Distance-Matched Random-Reference Diagnostic

This diagnostic explored a distance-matched random-reference control for the
IQL Gaussian observation-shift study.

The control was not promoted to a full experiment because the held-out Hopper
reference set did not provide sufficiently close alternative reference states
under the pre-specified matching criterion.

In the final diagnostic smoke test, only 8% of sampled cases had an alternative
reference within ±10% of the nearest-neighbor distance.

The diagnostic is retained for reproducibility and transparency but is not used
for inferential claims in the paper.
